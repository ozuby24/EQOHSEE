# Pengendalian Biaya

_Every Rupiah Traced_

Anggaran RKAB terhadap realisasi, biaya per ton dan per BCM, selisih yang dipecah menjadi bagian volume dan bagian tarif, serta proyeksi akhir tahun.

**Harga katalog:** Rp 8.500.000
**Halaman:** 5

Tangkapan layar di bawah memakai data contoh (`php artisan demo:pasang`),
bukan data pelanggan.
